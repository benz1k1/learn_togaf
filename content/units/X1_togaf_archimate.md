title: "Crosswalk: TOGAF and ArchiMate"

Crosswalk unit **X1 — TOGAF and ArchiMate**: which ArchiMate viewpoints draw each ADM phase and which language elements express each content-metamodel entity, as the ArchiMate specification's TOGAF appendix and the W14C harmonization paper set them out. The second lesson takes one Northgate Bank artefact and models it as an ArchiMate view in Archi, so the mapping is practised rather than memorised.
