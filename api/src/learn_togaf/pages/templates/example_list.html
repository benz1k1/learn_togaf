The standard defines each deliverable by its purpose and a contents list, but never shows one filled in. These documents are written for Northgate Bank, the same fictional retail bank the artefact drawings use, following one architecture project — Digital Channels: mobile payments, faster onboarding and fraud scoring — from the Preliminary Phase round the cycle to Phase H and a second Request for Architecture Work.

The same project is then drawn in ArchiMate — one view per viewpoint the ADM phase calls for, in the notation the OGA-031/032 papers show — and justified in SABSA: the Business Attributes Profile, the domain model and the Matrix cells filled in for the bank. Three descriptions of one enterprise; the crosswalk on each ADM phase says which belongs where.

Every document follows the contents list of its defining section (linked on each page). Names, figures and dates are invented for study; nothing here is a figure or template from the standard or the specification.
